# 生态决策

> STEP-02 中间产物（示例技能的完整流程产物）

## 目标生态

- [x] **仅 Claude Code** → `metadata.portability: "claude-code-only"`

理由：本技能需要 `argument-hint` 提供参数补全提示（`[from-ref] [to-ref]`），
这是 Claude Code 专有字段。跨生态分发时该字段会导致硬报错，因此明确标注为仅 CC 生效。

## L1 字段使用决策

| L1 字段 | 是否使用 | 理由 | 跨生态替代方案 |
|---|---|---|---|
| `argument-hint` | **是** | 两个参数（起始引用、结束引用）都可省略，需要补全提示告诉用户参数形态 | 无。若要去掉，只能在正文里用散文说明参数 |
| `disable-model-invocation` | 否 | 本技能只读历史 + 写一个 Markdown 文件，无不可逆副作用，可由模型自主触发 | — |
| `context` / `agent` | 否 | 单轮内可完成，无需子代理隔离 | — |
| 其他 | 否 | — | — |

## 触发方式

- [x] **model-invoked**（默认）

选择依据：本技能的副作用是「写一个 docs/releases/ 下的 Markdown 文件」，可逆（用户可删除），
且覆盖已有文件前有显式询问（见 SKILL.md 的 Failure modes）。因此允许模型自主触发，
用户说「生成发布说明」时即可介入，不必强制人工调用。

## 模型能力要求

无特殊要求。但需要 `gh` CLI 已认证（见 SKILL.md 的 Dependencies）。
